# Linux Fundamentals

Notes and exercises for learning Linux from the command line.

## Topics to cover

- [ ] Navigating directories: `pwd`, `ls`, `cd`
- [ ] Working with files: `touch`, `cp`, `mv`, `mkdir`, `rm`
- [ ] Reading text: `cat`, `less`, `head`, `tail`
- [ ] Searching: `grep`, `find`
- [ ] Permissions and ownership: `chmod`, `chown`, `id`
- [ ] Processes and services: `ps`, `top`, `systemctl`
- [ ] Logs and troubleshooting

## Practice notes

For each topic, add a short explanation, one or two examples, and a note about any mistakes or surprising results. Use a disposable practice directory when experimenting with file operations.
