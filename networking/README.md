# Networking Fundamentals

Learning notes for basic network concepts and diagnostic tools.

## Topics to cover

- [ ] IP addresses, private/public ranges, and subnet basics
- [ ] MAC addresses and ARP
- [ ] DNS resolution
- [ ] TCP vs. UDP and common ports
- [ ] HTTP and HTTPS basics
- [ ] Diagnostic tools: `ping`, `ip`, `ss`, `traceroute` / `tracepath`
- [ ] Packet capture and filtering with Wireshark

## Safe practice

Use diagnostic commands on your own device and networks, or in environments where you have permission. Capture traffic only when authorized, and review captures before sharing them to remove sensitive information.
