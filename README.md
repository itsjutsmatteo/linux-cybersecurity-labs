# Linux & Cybersecurity Labs

A beginner-friendly, hands-on learning repository focused on Linux fundamentals, networking, Bash scripting, and security basics.

> **Status:** Learning portfolio in progress. Each lab is documented as it is developed and tested.

## Goals

- Build confidence with the Linux command line and filesystem.
- Understand users, groups, permissions, processes, and system resources.
- Learn networking fundamentals such as IP addressing, DNS, HTTP, and packet analysis.
- Write small Bash scripts that automate safe, useful checks.
- Practice security concepts only in systems and environments where I have permission.

## Repository map

- `linux/` — Linux commands, filesystem, permissions, and process notes.
- `networking/` — networking concepts and diagnostic command notes.
- `scripting/` — Bash scripting notes and conventions.
- `labs/` — documented practical exercises and scripts.

## First lab

### System audit (read-only)

`labs/system-audit.sh` displays basic system information, uptime, memory and disk usage, and a short process list. It is intended for learning and does not change system settings.

Run it from the repository root:

```bash
bash labs/system-audit.sh
```

## Lab documentation template

For each new exercise, document:

1. **Objective** — what the exercise is meant to teach.
2. **Environment** — operating system and tools used.
3. **Steps** — commands run, with sensitive data removed.
4. **Observations** — what happened and what it means.
5. **Lessons learned** — what you understood or would investigate next.

## Safety and scope

All practice should be limited to personal devices, intentionally vulnerable labs, or systems for which explicit authorization has been granted. Do not publish passwords, tokens, private IP details that you do not wish to disclose, or other sensitive information.
